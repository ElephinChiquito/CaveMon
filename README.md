# CaveMon
CaveMon es un juego de aventuras RPG 2D en pixel-art inspirado en los clásicos por turnos. Explora cavernas y entrena monstruos elementales (fuego, agua, hoja). Incluye ejecutable independiente para Windows con JRE embebido y recursos organizados. ¡Controla con WASD, interactúa con E y combate con los menús numéricos!
